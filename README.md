# Pygame-Demo
A small game I made using pygame. Includes a few useful libraries I've wrote in my own.

# The Goal of the Game
You control both knight and selection box in a turn based game. Knight is weak alone, but when you catch monsters with selection box, they became vulnerable. You can only kill vulnerable monsters.

# Benefits of this Project
I made my own pygame menu system to make game menus easier. They are in the SPRITES.py file. I have 3 classes for it.
1. BUTTON & TEXT class, so you can add buttons anywhere on the screen and color them easily.
2. MENU class, you can store buttons and texts in MENU classes.
3. DIALOG class, so you can display dialogs with just a single line of code.
